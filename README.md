# 三国杀台词插件 (Sanguosha Quotes Plugin)

你的 QQ 群聊好友中是否有三国杀爱好者喜欢娘念台词？这是一个为 MaiBot 开发的简易插件，支持两种互动方式：

1. 发送 `/三国杀` 指令，自动从本地台词库中随机抽取一句并发送。
2. 发送 `/武将名称` 指令（如 `/张飞`），自动从本地台词库中随机抽取一句该武将的台词并发送。

## 目录结构

确保你的插件目录结构如下（所有文件必须放在同一个文件夹内）：

```text
sanguosha_plugin/
├── _manifest.json              # 插件元数据配置（必须）
├── plugin.py                   # 核心代码（入口文件必须是这个名字）
├── sanguosha_quotes.txt        # 三国杀台词库（UTF-8 编码，格式：武将名：台词）
├── .gitignore                  # Git忽略文件
├── LICENSE                     # MIT 开源协议
└── README.md                   # 说明文档（本文件）
功能特点
指令触发：在群聊中发送 /三国杀 即可随机抽取全局台词；发送 /武将名称（如 /张飞）即可随机抽取该武将的台词。

本地词库：台词库独立存放在 sanguosha_quotes.txt 中，方便随时增删改查。

安装与使用
将整个 sanguosha_plugin 文件夹放入 MaiBot 的 plugins/ 目录下。

重启 MaiBot 核心，确保在控制台日志中看到类似以下信息：

text
三国杀台词插件已加载，正在读取台词库...
成功加载了 XXXX 名武将的台词！
在 QQ 群聊中发送 /三国杀 随机抽取全局台词，或发送 /武将名（如 /关羽）抽取指定武将的台词。

自定义台词库
如果你想增加或删减台词：

用文本编辑器打开 sanguosha_quotes.txt。

严格按照 武将名：台词内容 的格式编辑（注意是全角中文冒号）。

保存文件，重启 MaiBot 即可生效。

常见问题排查
Q1: 在 WebUI 点击开关时提示"切换插件状态失败"？

原因：入口文件名错误或 SDK 版本不匹配。

解决：确保 Python 入口文件叫 plugin.py，且 _manifest.json 中的 sdk 版本上限足够高（如 999.999.999）。

Q2: 日志提示 JSON 校验失败，或插件未显示在列表中？

原因：_manifest.json 格式错误。

解决：检查 JSON 格式是否严格。注意：id 必须全小写且格式如 author.plugin_name。
