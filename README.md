\# 三国杀台词插件 (Sanguosha Quotes Plugin)

你的qq群聊好友中是否有三国杀爱好者喜欢娘念台词？输入/三国杀来搞耍他吧！这是一个为 MaiBot 开发的简易插件，用于在 QQ 群聊中检测到 `/三国杀` 指令时，自动从本地台词库中随机抽取一句三国杀台词并发送。

目录结构

确保你的插件目录结构如下（所有文件必须放在同一个文件夹内）：

```text
sanguosha_plugin/
├── _manifest.json              # 插件元数据配置（必须）
├── config.toml                 # 插件运行配置（必须，防止 SDK 读取失败）
├── plugin.py                   # 核心代码（入口文件必须是这个名字）
├── sanguosha_quotes_pure.txt   # 三国杀台词库（UTF-8 编码）
└── README.md                   # 说明文档（本文件）



功能特点

\- \*\*指令触发\*\*：在群聊中发送 `/三国杀` 即可触发。

\- \*\*随机抽取\*\*：每次触发都会从数千条三国杀武将台词中随机抽取一句，拒绝重复枯燥。

\- \*\*本地词库\*\*：台词库独立存放在 `sanguosha\_quotes\_pure.txt` 中，方便随时增删改查，无需修改代码。



文件说明

\- `\_manifest.json`：插件的“身份证”，包含版本、ID 等元数据，MaiBot 加载插件时必须校验此文件。

\- `plugin.py`：插件的入口代码，负责读取台词库、监听指令并发送消息。

\- `sanguosha\_quotes\_pure.txt`：存放三国杀台词的纯文本文件（每行一句）。



安装与使用

1\. 将整个 `sanguosha\_plugin` 文件夹放入 MaiBot 的 `plugins/` 目录下。

2\. 重启 MaiBot 核心，确保在控制台日志中看到类似以下信息：

&#x20;  > `三国杀台词插件已加载，正在读取台词库...`

&#x20;  > `成功加载了 XXXX 条三国杀台词！`

3\. 在 QQ 群聊中发送 `/三国杀`，机器人即可随机回复一句台词。



自定义台词库

如果你想增加或删减台词：

1\. 直接用文本编辑器（如记事本、VS Code）打开 `sanguosha\_quotes\_pure.txt`。

2\. 每行写一句台词（空行会被自动忽略）。

3\. 保存文件，重启 MaiBot 即可生效。



注意事项

\- 请确保 `sanguosha\_quotes\_pure.txt` 的编码为 \*\*UTF-8\*\*，否则可能会导致中文乱码或读取失败。

\- 如果你的台词文件中包含类似 `colspan="2"` 或 `【信息暂缺】` 的无效行，插件也会将其当作普通台词抽取。建议在文本编辑器中按 `Ctrl+H` 搜索并删除这些无效行。



常见问题排查

\- Q1: 在 WebUI 点击开关时提示“切换插件状态失败，插件配置运行时不可用，无法读取配置定义”？

\- 原因：MaiBot 找不到配置文件，或者入口文件名错误。

\- 解决：1. 确保目录下有 config.toml 文件（哪怕里面没内容）。2. Python 入口文件必须叫 plugin.py，不能是 sgs_plugin.py 等其他名字。

\- Q2: 日志提示 JSON 校验失败，或插件未显示在列表中？

\- 原因：_manifest.json 格式错误。

\- 解决：检查 JSON 格式是否严格（末尾不能有多余逗号，不能有注释）。里面的 id、version、urls.repository 等字段均需符合规范（id 不能为中文，版本号必须是 1.0.0 三段式，URL 必须是 https:// 开头）。
